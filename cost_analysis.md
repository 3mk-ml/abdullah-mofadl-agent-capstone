# DocPilot AI - Cost Analysis

**Provider:** OpenAI API. **Model:** `gpt-6-luna` (Responses API). **Date of pricing lookup:** November 4, 2026.
**Source:** https://developers.openai.com/api/docs/models/gpt-6-luna

## Rates and calculation

Standard published text-token rates at the time of writing:

- Uncached input: **$0.10 per 1,000,000 tokens**.
- Cached input: **$0.01 per 1,000,000 tokens**.
- Cache writes (when applicable): **$0.125 per 1,000,000 tokens**.
- Output (including reasoning tokens): **$0.50 per 1,000,000 tokens**.

For a non-cache-writing call, the estimated charge is:

`((input_tokens - cached_input_tokens) * 0.10 + cached_input_tokens * 0.01 + output_tokens * 0.50) / 1_000_000`

The program captures OpenAI-reported input/output/cached counts per call in SQLite `usage` and emits an accumulated USD estimate in the JSONL trace. Because cache-write details, provider billing adjustments, long-context prices, and exchange rates may differ, the local estimate is **not an invoice**. The reservation test uses a conservative input price of $0.125/M plus a maximum of 900 output tokens to block a task before a new call would exceed the cap.

## Task budget and worked example

- **Task cap:** $0.03, enforced in code.
- **Max model calls:** 8; **maximum output:** 900 tokens per call.
- Example only (not observed): 4 calls each with 2,000 uncached input tokens and 500 output tokens would cost `4 * ((2000 * 0.10 + 500 * 0.50) / 1_000_000) = $0.0018` total.
- An agent may terminate sooner if source evidence is missing or authorization denied.
